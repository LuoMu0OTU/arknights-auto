# 用户指南（新用户上手）

> 面向第一次接触本项目的玩家：从下载到跑完日常的全部步骤。
> 项目仓库：<https://github.com/LuoMu0OTU/arknights-auto>

---

## 0. 这是什么

一个跑在**你自己电脑上**的《明日方舟》官方 PC 客户端自动化助手：
用截图 + 图像识别 + 模拟点击驱动游戏，**不注入进程、不修改游戏文件、不用模拟器**。

能做的事（截至 v0.2.0）：

| 功能 | 状态 | 说明 |
|---|---|---|
| 自动刷图 | ✅ 可用 | 前往上一次作战 → 代理指挥 → 打一场 → 识别战报收尾 |
| 基建收菜 | ✅ 可用 | 进基建、点发光制造站/贸易站恢复生产、会客室线索全套、多轮循环 |
| 公开招募 | ✅ 可用 | 识别标签选词条、聘用已完成候选人、自动设 9:00 计时 |
| 好友访问 | ✅ 可用 | 好友列表逐个访问基建 |
| 信用商店 | ✅ 可用 | 按配置优先级购买（默认招聘许可/寻访凭证） |
| 任务/邮件/签到 | ✅ 可用 | 日常+周常「收集全部」、邮件一键收取、每日签到 |
| 自动更新检查 | ✅ | 启动检查 GitHub Release，可关闭 |
| 多配置方案 / 诊断包导出 | ✅ | 设置页操作 |

**不支持**：基建换班、选关导航（当前只打「上一次作战」）、定时任务、系统托盘（计划中）。

## 1. 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 1903+ / Windows 11，64 位 |
| 游戏 | 明日方舟 **官方 PC 客户端**，已安装并能正常登录 |
| 权限 | 游戏需要**管理员权限**运行；本程序连接游戏时可能弹一次 UAC |
| 显示 | 游戏窗口 **1280×720、16:9、UI 缩放 100%**（其他分辨率未验证） |
| 网络 | 首次启动需联网下载识别资源（约几百 MB） |
| 磁盘 | 约 1 GB 空余 |

> ⚠ 部分精简系统缺 `vcruntime140.dll`：若双击报错，安装
> [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe) 即可。

## 2. 下载与首次启动（5 分钟）

1. 打开 **Releases 页面**：
   <https://github.com/LuoMu0OTU/arknights-auto/releases/latest>
2. 下载 `ArknightsAuto-windows.zip`（约 110 MB）。
3. **解压到任意目录**（不要放 C 盘 Program Files，避免权限问题）。
   解压后应看到：
   ```
   ArknightsAuto/
     arknights-auto.exe     ← 双击这个
     _internal/             ← 运行时（不要动）
   ```
4. 双击 `arknights-auto.exe`，首次启动会弹「**首次启动向导**」：
   - **环境检查**：Python 运行时（已内置）、MaaFramework 动态库自检；
   - **游戏路径**：自动检测 `E:\Arknights\Arknights.exe`，不对可手动选；
   - **资源下载**：自动下载模板图/OCR 模型（需联网，进度条可见）；
   - **配置生成**：在 exe 旁生成 `config/`、`logs/`、`assets/`（可写数据与程序分离）。
5. 向导完成后进入主界面。

> 第一次启动若杀毒软件报毒：PyInstaller 打包的未签名程序常被误报，
> 把解压目录加入信任即可（源码完全公开可自行审计）。

## 3. 日常使用

### 简单模式（推荐）

1. 启动 `arknights-auto.exe`；
2. 首页确认「游戏已连接」（游戏需先启动并保持**窗口化/非最小化**）；
3. 选择预设：
   - **每日常规**：刷图 + 基建 + 公招 + 信用 + 领奖全套；
   - **快速收菜**：只做基建收菜；
   - **公招与信用**：公招 + 信用商店；
   - **自定义**：自己勾任务。
4. 点「**开始**」→ 看进度与结果；
5. 随时可点「**停止**」（安全中断，不会留下失控点击）。

### 高级模式

- 可调：刷图次数、理智策略、公招词条、信用购买优先级、任务顺序、重试/超时；
- **切换简单/高级模式不会重置你的配置**；
- 配置都是 exe 旁 `config/config.json`，可直接编辑或导出。

### 运行记录

- 每次运行在 `logs/run-<时间戳>.json` 有完整报告（每任务成功/失败/耗时）；
- 设置页可「**导出诊断包**」（脱敏后打包日志+配置，方便反馈问题）。

## 4. 常见问题

| 问题 | 原因与解决 |
|---|---|
| 连接失败：窗口句柄无效 | 游戏被最小化/关闭。程序会自动恢复窗口；仍失败则手动把游戏窗口拖出来 |
| 战斗后后续任务全失败 | 战斗全屏独占导致截图失效，已做「每任务前截图自愈」，若仍出现请反馈日志 |
| 基建卡住/漏收 | 程序会回主界面再进基建重收一轮；蓝色铃铛消失即表示收菜完成 |
| 公招不动 | 若 4 个槽位都是「已找到候选人」，程序会先聘用再重新招募 |
| 识别错字/点错位置 | 分辨率或 UI 缩放不是 1280×720/100%——请调整游戏设置 |
| 更新检查 | 启动时自动查新版本；可在设置关闭 |

## 5. 从源码运行（开发者）

```powershell
git clone https://github.com/LuoMu0OTU/arknights-auto.git
cd arknights-auto
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe -m ak_auto fetch-assets   # 下载识别资源
.\.venv\Scripts\python.exe -m ak_auto gui            # 启动 GUI
.\.venv\Scripts\python.exe -m ak_auto daily          # 或直接跑日常
```

构建便携包：`python tools/build_windows.py`（产物 `dist/ArknightsAuto/`），详见 [BUILD.md](BUILD.md)。

## 6. 安全与免责

- 本工具**只**读取屏幕截图并模拟键鼠，不修改游戏内存/文件、不注入进程；
- 第三方自动化可能涉及游戏服务条款，**账号风险请自行评估**；
- 付费资源（源石等）相关操作**默认关闭**，需在配置中显式开启；
- 项目许可证 AGPL-3.0，识别素材参考 [MaaAssistantArknights](https://github.com/MaaAssistantArknights/MaaAssistantArknights)（LGPL-3.0），详见 [NOTICE.md](../NOTICE.md)。
