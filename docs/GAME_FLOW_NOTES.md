## 0. 铁律（每条都踩过坑）

| # | 规则 | 反例/后果 |
|---|---|---|
| 1 | `next` 与 `on_error` 不能重叠 | 触发 MaaFw `error handling loop detected`，任务直接失败 |
| 2 | `next` 是候选列表，第一个识别命中者执行 | 可选步骤必须放候选链，不能串成硬链 |
| 3 | DirectHit 节点没有截图，CustomAction 读图会崩 | CustomAction 节点必须带一个识别 |

| 7 | 动画相关步骤不能太快 | 公招点击过快导致流程失败 |
| 8 | **点击后用 `ctrl.cached_image` 判断结果 = 永远看到点击前的画面** | CustomAction 里 `cached_image` 是「本节点识别时」的旧帧，点击后不刷新 → 铃铛点了却判定"没打开"，收菜静默跳过（2026-11-02 修复，改用 `post_screencap` 抓新帧） |

## 2. 基建收菜

### 收菜的定义（负责人口径）
> **把左下角「待办事项」右边的按钮全部点完，才算收成功。**

待办事项条（底部 y≈680）从左到右可能出现的按钮：

| 按钮 | 含义 |
|---|---|
| 可收获 | 设施产物（制造站/贸易站等） |
| 干员信赖 | 干员信赖值 |
| 队列轮换 | 换班队列 |
| 干员疲劳 / 干员休整 | 疲劳干员换班 |

- 位置随计数变化 → **OCR 定位按钮文字后点文字中心**，不要写死 x 坐标。
- 蓝铃铛是**开关**：待办条已开时再点会关掉 → 实现上「先找按钮，找不到才点铃铛」。

#### 待办条开/关的真机实测（2026-11-02，1281×720）

| 状态 | 左下角 | 判断方式 |
|---|---|---|
| 条**收起** | 只有基地地图（无任何文字） | 读不到「待办事项」标签 |
| 条**打开** | 深色条 + 「✓待办事项」+ 右边若干按钮 | OCR 到「待办事项」标签（按钮为 0 个时条仍开着） |

- **铃铛位置**：无 ⚠ 时通知按钮在 **(1242,97)**（白色面板 + 蓝色铃铛 + 蓝色数字角标）；此时 **(1242,133) 点空**。
- **待办项清空后待办条自动收起**，同时右上角铃铛和数字角标一起消失（此时再点铃铛没有反应，属正常）。
- 按钮点击效果：`订单交付`（气泡「1点击全部交付」）点一次即交付全部订单；`干员休整`（气泡「2个干员」）一次只处理一个，按钮会保留，需要重复点。
- 「待办事项」是**标签不是按钮**（点它没反应）。

### 特殊待办项
> 「有些是特殊的，光点待办没用，还要再点一下基地地图上对应的具体设施（就像会客室，其它设施一般点一下即可）。」

- **会客室**（已验证完整流程）：进房间 → 左下「搜集中」→ 线索板 →
  `快捷置入` → `线索交流` → `接收线索→全部收取→点左侧空白返回` →
  `传递线索→左下角(一键递送)→右上×` → `线索→空白返回` → `信用奖励→领取→×` → `<` 返回基地。
- 基地地图上**点制造站/贸易站会进入该设施房间**（不是收菜），进去后必须 `返回(<)` 再继续。

### 设施状态判读
- 制造站黄色粗边框、发电站绿色、贸易站青色。
- `生产中 ▶` = 正常；`已停止`（橙色） = 停工。
- 停工判断用**状态文字颜色**：状态区黄色像素 < 12 判为停工（生产中黄字 24~38 px，已停止橙字≈0）。
- 站名 OCR：`制造站`/`贸易站` 开头；**必须排除 `制造站B3xx` 这类房间标题**（进房间后标题会误判）。

### 时序（2026-10-31 修复）
- 第 1 轮结束点 `<` 回主页后 **等 4 秒**再进第 2 轮（原来 2.5 秒导致第 2 轮 Enter 点空）。
- 进基建后 **等 5 秒**再识别。

## 4. 公开招募

### 负责人口径
> 「玩家做日常时，公招都是前一天已经选好了；第二天脚本应该**先把昨天已完成的候选聘用了，再招募新的**。」

实际存在多个槽位同时有候选人的情况，必须循环处理。

### 流程
1. 主页 → 公开招募（入口中心 **(975,482)**；紧右边 (1085+) 是「干员寻访」，点偏会进错页）
2. 处理所有「聘用候选人」→ 动画（先 OCR `SKIP` 再点）→ 结果页点掉 → 回招募页
3. 无候选后「开始招募干员」→ 选标签 → 设时长 → 确认

### 关键参数
- **识别区域必须覆盖全部 4 槽位**：1 号槽位按钮 y≈215，2~4 号 y≈330/620 → roi `[0,150,1281,570]`
- **识别词用短词「聘用」**（长词「聘用候选人」在全宽 ROI 下被相邻文字干扰，漏掉 3 号槽位）
- **动画节奏**：聘用后等 3 秒 → 点跳过（先 OCR SKIP，别盲点）→ 结果页每次点完等 2.5 秒

### 标签选择策略（`data/recruitment.py: best_selection`）
1. `recruit.tag_priority` 中命中的标签 → 单独选它（职业名也可写）
2. 否则找**保底 4★** 最优组合
3. 再否则保底 3★ 组合
4. 最后选单个最高星级标签

⚠ **单独选职业标签（重装干员等）通常只出 3★**；要高星应留空或写「高级资深干员 / 资深干员」。GUI 位置：任务中心 → 公开招募 → ⚙ → 「标签优先级（真实生效）」。

## 6. 弹窗与异常

- 常见遮挡：签到奖励（`累计签到/特别物资`）、活动公告、180 天特别物资、断线重连、邮件通知。
- 处理原则：OCR 命中弹窗文字 → 点右上 ×（位置会变，优先 OCR 定位文字后偏移）。
- **弹窗会连锁弹出**（如 180 天物资 → 十月签到）。
- **游戏窗口被最小化/伪最小化时截图返回 `client_rect=-32000`**：需 `restore_window`（ShowWindow SW_RESTORE + SW_SHOW + SetForegroundWindow）恢复；普通恢复失败时用 ctypes 强制恢复。
- 战斗后可能停在「请选择需要保存的代理指挥记录」页，需点底部确认 (640,660) 再回主页。
